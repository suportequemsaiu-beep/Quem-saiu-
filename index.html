Política de Privacidade — Quem Saiu

Última atualização: 15 de agosto de 2026.

O que a extensão faz

A extensão "Quem Saiu" lê, na própria página do Instagram já aberta no seu navegador, a lista de contas exibida em um modal de "seguidores" ou "seguindo" (nomes de usuário visíveis na tela), e salva essa lista localmente para comparar com uma captura futura.

O que NÃO fazemos

  • Não pedimos nem armazenamos login, senha ou qualquer credencial do Instagram.
  • Não enviamos nenhum dado para servidores externos — não existe backend.
  • Não rastreamos sua navegação fora das páginas do instagram.com.
  • Não compartilhamos, vendemos ou usamos os dados capturados para qualquer outra finalidade.

Onde os dados ficam guardados

Os snapshots (listas de nomes de usuário e a data da captura) ficam salvos apenas no armazenamento local do seu navegador (chrome.storage.local), vinculado ao seu perfil de navegador neste dispositivo. Desinstalar a extensão apaga esses dados.

Permissões solicitadas

  • storage — para guardar os snapshots localmente.
  • activeTab / scripting — para ler a lista de contas na aba ativa do Instagram quando você aciona a captura.
  • host_permissions para instagram.com — necessário para o content script funcionar apenas nesse domínio.
